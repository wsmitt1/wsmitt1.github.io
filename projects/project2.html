Space Survivor

A Survivors-like bullet hell game with rapid enemy scaling.

Unity C# Solo Project

Overview

Space Survivor is a bullet hell game inspired by the popular game Vampire Survivors. The game features rapid enemy scaling, where the number of enemies and their health increases exponentially as you progress. The goal of the game is to survive as long as possible while defeating waves of enemies and collecting power-ups.

Challenges

The main challenge during this project was handling performance issues caused by the large amount of enemies and projectiles on the screen at once. I had to optimize the code and use object pooling to ensure that the game ran smoothly even with a large number of enemies and projectiles. This was also my first time using many of the Unity features I implemented in this project, such as the particle system and the weapons, so there was a learning curve involved in figuring out how to use these features effectively.

What I Learned

This project gave me a deeper understanding of many core Unity features aswell as general game development concepts such as performance optimization and game design. I learned how to use the particle system to create visually appealing effects, and I also learned how to implement a weapon system that allows for different types of weapons with unique behaviors.
