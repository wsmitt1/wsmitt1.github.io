The CEO Must Go

A chaotic physics game where you play as a disgruntled employee. Built at FutureGames.

Unreal C++ Blueprint Team Project

Overview

The CEO Must Go is a chaotic physics game where you play as a disgruntled employee trying to take down your evil and self-absorbed CEO. The game features a variety of weapons and upgrades that you can use to defeat the CEO and his minions. You progress through the game by reaching Combo goals on each level, and you travel through the Elevator and purchase upgrades to get ready for the next floor. The final floor is the CEO's office.

Challenges

This project was my first full Unreal Engine project and also the longest Game Project at FutureGames, and I learned a lot about the engine and its features. One of the biggest challenges was learning how to use Unreal's Blueprint system effectively, as well as learning how to implement a weapon system that allows for different types of weapons with unique behaviors. Even though the learning curve was steep, me and my team managed to create a fun and chaotic game that we are proud of. The project was also a great opportunity to learn about collaboration and code structure in Unreal.

What I Learned

This project was to me like a crash course for Unreal, C++ and Blueprints. It was overall a great learning experience and also improved my general programming and code structuring skills.
